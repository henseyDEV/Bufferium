# Bufferium V1.00 (by rippd)

Install BOTH files in Geometry Dash/geode/mods/:
  1. FWCmain-quiet.geode   (the original buffer mod, patched so it never opens its console)
  2. Bufferium.geode       (this mod, built from this project)
Remove the old FWCmain.geode first.

- F7 or F8: show / hide the Bufferium panel (inside a level)
- Pause screen: a BUFFER button also opens the panel
- Checkbox: buffer on / off
- Chips: 2/2, 4/4, 8/8, 16/8
- Open Console / Close Console: the live console is only shown when you ask for it
- Closing the console window with its X switches the buffer OFF instead of closing the game
